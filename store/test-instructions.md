# Test instructions（给审核员，用英文）

后台：Developer Dashboard → **Test instructions / 审核说明**。

```
How to test File Sample Library (no account required).

1. Install the extension.
2. Click the toolbar icon. A popup lists built-in sample files (TXT, JSON, PDF, MP3, MP4, DWG, and others).
3. Use the category tabs (All / Text / Data / Media / CAD / Mine) or the search box.
4. Click the download icon on any row. The file should appear in the browser’s default Downloads folder.
5. Optional: click 导入 (Import), choose a file under 2 MB. It should appear under 我的 (Mine) and can be downloaded or removed.

Notes
- No login, no sample credentials, no network required.
- The only permission is downloads, used only after the user clicks Download.
- Imported files stay in IndexedDB on this device and are never uploaded.
```
